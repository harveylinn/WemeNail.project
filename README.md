# 💅 WemeNail | 美甲工作室形象網站

WemeNail 是一個以美甲工作室為主題的前端網站專案，提供品牌介紹、作品展示、服務資訊及線上預約表單介面。

本專案以 **HTML、CSS、JavaScript** 開發，著重於網頁排版、使用者操作體驗、前端互動功能及表單驗證。

## ✨ 專案功能

### 🏠 首頁
- 展示品牌形象與工作室特色
- 提供網站導覽及各頁面入口

### 💅 作品集
- 展示不同風格的美甲作品
- 提供圖片瀏覽與作品展示介面

### 🏡 關於工作室
- 介紹工作室及相關服務資訊
- 提供聯絡方式與相關資訊

### 📅 線上預約
- 提供預約表單介面
- 使用 JavaScript 進行前端表單驗證
- 顯示預約送出後的成功提示

> **注意：** 目前預約功能為前端展示與操作流程，尚未串接後端 API 或資料庫，預約資料不會實際儲存。

## 🚀 如何執行

本專案為前端靜態網站，不需要安裝額外的套件或啟動後端伺服器。

1. Clone 專案：

```bash
git clone https://github.com/harveylinn/WemeNail.project.git
```

2. 進入專案資料夾：

```bash
cd WemeNail.project
```

3. 使用瀏覽器開啟 `首頁.html`，即可瀏覽網站。
